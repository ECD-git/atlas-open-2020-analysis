# Four Lepton Analysis
A four lepton analysis to find the mass of the Higgs boson, using the 2020 Cern open data portal release. A small exercise to familiarize myself with the ROOT library and learn more about data analysis at CERN, to then be further applied in a more in depth manner later on.

# Dependencies
- ROOT library (TFile.h, TTree.h, TH1F.h, THStack.h, TLegend.h)
- json.hpp (https://github.com/nlohmann/json)
- STD::Math

# Features
V0.0
- Read root files downloaded from CERN data releases.
- Apply calculations to data read from data files.
- Invariant mass calculation to 4lepton data sets. (through my own 4vector library as well as ROOT's inbuilt one)
- Draw analyzed data onto a histogram.
- Read JSON files and map dictionaries.
- Iteration over sets of data files.
- Calculate statistical significance of the Higgs signal against the background for simulations.
- Isolate specific lepton types (eg leading, sub leading) to see transverse momentum distributions.
- Cut Monte-Carlo leptons by their transverse momentum.
